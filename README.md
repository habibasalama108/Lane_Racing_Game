🏎️ McQueen Lane Dodging Game

A real-time game controlled by hand gestures using Computer Vision and YOLO.

🎮 Features

✋ Open Palm: Controls McQueen's movement between lanes.

✌️ Peace Sign: Activates Kachow Boost.

🛢️ Obstacles: Spawn randomly and move toward McQueen.

⚡ Nitro: Collect Nitro points and use them for boosting.

💥 Collision Detection: Detects collisions with obstacles.

🔥 Kachow Boost: Temporarily protects McQueen and clears obstacles.
